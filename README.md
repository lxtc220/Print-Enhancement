# PrintEnhance Pro - PDF打印增强工具

## 项目简介

PrintEnhance Pro 是一款专业的PDF打印增强工具，专为解决彩色PDF转换为黑白打印时出现的颜色过淡问题而设计。当您需要将彩色PDF文档打印成黑白版本时，经常会遇到某些颜色（如浅色、黄色等）在转换为灰度后变得几乎看不见的情况。

本工具通过先进的伽马校正技术和颜色权重调整，确保所有内容在黑白打印时都能清晰可见，特别适合处理技术文档、学术论文、设计图纸等包含多种颜色的专业文档。

## 主要功能

1. **自定义颜色权重**：允许调整红、绿、蓝三原色的权重，优化不同颜色的灰度转换效果
2. **伽马校正**：通过伽马校正调整图像对比度，确保浅色内容在黑白打印时清晰可见
3. **实时预览**：提供原始图像和处理后图像的并排预览，支持缩放和拖拽
4. **多页PDF支持**：可以处理多页PDF文档，支持页面导航
5. **多种预设**：提供标准灰度、复古、蓝调、加强黄色等多种预设方案
6. **灵活输出**：支持多种输出格式和压缩选项

## 技术特点

- 使用PyMuPDF进行PDF处理，确保高质量渲染
- 基于PyQt6的现代化图形界面
- 支持高分辨率PDF处理
- 多线程处理，避免界面冻结
- 精确的颜色权重控制（精确到0.001）

   - 点击"浏览..."按钮选择要处理的PDF文件

3. 参数调整：
   - **颜色权重**：可调整红、绿、蓝三原色的权重，但对解决颜色过淡问题作用有限

## 参数说明

### 颜色权重

- **红色权重**：控制红色在灰度转换中的比重
- **绿色权重**：控制绿色在灰度转换中的比重
- **蓝色权重**：控制蓝色在灰度转换中的比重

### 预设方案

- **标准灰度**：使用标准灰度转换公式（R:0.299, G:0.587, B:0.114）
- **复古**：模拟老照片效果，增强暖色调
- **蓝调**：增强蓝色调，适合技术文档
- **加强黄色**：特别增强黄色权重，解决黄色内容过淡问题

### 伽马校正

- **核心参数**：对解决颜色过淡问题效果最显著的参数
- 推荐值：**-0.5**（针对解决颜色过淡问题）
- 正值使图像对比度增强，浅色部分变暗
- 负值使图像对比度降低，深色部分变亮
- 对于解决颜色过淡问题，建议使用负值（推荐-0.5）

## 输出设置

- **输出格式**：支持JPEG、PNG、WEBP格式
- **压缩质量**：10-100，数值越高质量越好但文件越大
- **启用压缩**：可选择是否启用图像压缩

## 常见问题

1. **为什么某些颜色打印后几乎看不见？**
   - 这是因为标准灰度转换中，某些颜色（如黄色）的灰度值很低，导致打印后几乎看不见。

2. **如何解决黄色内容过淡的问题？**
   - 将伽马校正值设置为-0.5，这是解决颜色过淡问题的最有效方法
   - 颜色权重调整对解决此问题作用有限，可以尝试"加强黄色"预设作为辅助

3. **处理大PDF文件时程序卡顿怎么办？**
   - 程序使用多线程处理，但处理大文件仍需要时间，请耐心等待进度条完成。

4. **如何获得最佳打印效果？**
   - 首先将伽马校正值设置为-0.5，这是解决颜色过淡问题的关键
   - 建议先处理一页进行测试打印，根据实际效果微调参数
   - 如果-0.5效果不够明显，可以尝试更负的值（如-0.6到-0.8）

## 技术实现

本工具的核心算法基于以下原理：

1. **加权灰度转换**：
   ```
   灰度值 = R × 红色权重 + G × 绿色权重 + B × 蓝色权重
   ```

2. **伽马校正**：
   ```
   校正后值 = 原始值^(1/(1+伽马值))
   ```

3. **高分辨率渲染**：
   使用3倍分辨率渲染确保细节清晰，适合高质量打印需求。
